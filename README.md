# 🐍 Python IT Automation Toolkit

A practical Python automation project designed to automate common IT support and system administration checks.

The toolkit collects system information, checks network connectivity, monitors disk usage and produces a simple health report.

## 🎯 Objectives

- Automate repetitive IT support checks
- Collect system information
- Test network connectivity
- Monitor disk usage
- Generate structured health reports
- Reduce manual troubleshooting effort
- Demonstrate Python scripting for IT operations

## 🛠️ Technologies

- Python 3
- Standard Python libraries
- Networking
- System administration
- Command-line tools

## 🔧 Features

### System Information

Collects:

- Hostname
- Operating system
- Python version
- Current user

### Network Check

Tests connectivity to configured endpoints.

### Disk Check

Checks disk usage and reports potential storage issues.

### Health Report

Combines the results into a readable report.
